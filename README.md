# 🚀 Yogesh Gate - Portfolio Website

A modern, responsive portfolio website showcasing projects, technical skills, and professional achievements in full-stack development and data science.

## ✨ Features

- 📱 **Fully Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- 🎨 **Modern UI/UX** - Clean, professional interface with smooth animations and transitions
- 🔗 **Complete Navigation** - Easy access to all sections with smooth scrolling
- 💼 **Project Showcase** - Featuring 15+ completed projects
- 📊 **Skills Display** - Comprehensive technical skills and core competencies
- 📄 **Resume Integration** - Direct download link to resume
- 🤝 **Contact Integration** - Multiple contact channels (email, LinkedIn, GitHub, Telegram, Instagram)
- ⚡ **Performance Optimized** - Fast loading times with optimized assets

## 🛠 Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Fonts:** Google Fonts (Outfit family)
- **Icons:** Font Awesome 6.5.2
- **Hosting:** GitHub Pages
